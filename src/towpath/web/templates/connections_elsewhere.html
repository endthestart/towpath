Connections

Accounts are added and managed by Towpath's connector service, the only part of Towpath that handles passwords. It isn't reachable at this address.

In a deployment, the reverse proxy sends /connections/ to the connector (towpath connect serve-setup); see the Hub setup guide. For local development, run that command and open its address.
