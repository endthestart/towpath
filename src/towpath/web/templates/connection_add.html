First, make an app password in Fastmail

  1. In Fastmail, open Settings → Privacy & Security, then Manage app passwords and access, and choose New app password.
  2. Name it Towpath. For access, choose IMAP and tick Read-only.
  3. Choose Generate password, copy it, and paste it below. Fastmail shows it only once.

Towpath only reads: it never changes, moves, deletes or marks mail as read, and a read-only password means Fastmail enforces that too. You can revoke the password in Fastmail at any time. Fastmail's help on app passwords

First, make an app password in Google

  1. App passwords need 2-Step Verification on your Google account. Then open Google's app passwords page.
  2. Name it Towpath (reading), create it, and paste the 16 letters below.
  3. In Gmail's settings, under Forwarding and POP/IMAP, IMAP must be on.

Google's app passwords can't be limited to reading, so Towpath's own code enforces it: the reading connection only examines folders and reads with peeks, and nothing is changed. Towpath reads All Mail (every message once) and the Inbox by default. Mail management can later use a second app password to change mail.
