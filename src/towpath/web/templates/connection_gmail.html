One-time setup in Google Cloud

Google requires each self-hosted app to use its owner's own sign-in client. Do this once; every Gmail account you add afterwards just signs in.

  1. Open Google Cloud → Google Auth Platform → Clients in the project you use for Towpath (the one with the Gmail API enabled).
  2. Choose Create client. Application type: Web application. Name: Towpath.
  3. Under Authorized redirect URIs, choose Add URI and paste exactly:
    {{ redirect_uri }}
  4. Choose Create, then copy the Client ID and Client secret into the form below.
  5. Under Audience, check the publishing status is In production. In “Testing”, Google ends the sign-in after 7 days.

Towpath only asks to read your mail, and turns down anything more. Because this sign-in client is your own and not reviewed by Google, Google shows an “unverified app” warning when you sign in: choose Advanced, then continue.
