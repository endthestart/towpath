First, make an app password in Fastmail

  1. In Fastmail, open Settings → Privacy & Security → App passwords and choose New app password.
  2. Name it “Towpath (contacts and calendars)”. For access, choose Contacts and calendars (CardDAV/CalDAV) and tick Read-only.
  3. Paste it below. It's separate from the mail passwords.

Towpath only reads: it asks the server for lists and items, and never adds, changes or deletes a contact or an event.
